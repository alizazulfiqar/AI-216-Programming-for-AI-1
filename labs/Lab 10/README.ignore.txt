In Lab 10, I learned how to build a complete end-to-end AI system by organizing machine learning code into separate modules — preprocessing.py, train.py, evaluate.py, predict.py, and main.py — which taught me how real-world AI projects are structured instead of writing everything in one script. I understood how data flows through a pipeline, how to save and reload a trained model using joblib, and how to simulate deployment by predicting on a single sample. The main difficulties I faced were with Jupyter Notebook not recognizing local file imports like from preprocessing import load_data, which caused red underline errors that looked like code mistakes but were actually environment issues, and I also struggled with special characters in dictionary keys like 'KNN (k=5)' breaking the syntax highlighting, as well as variables like X and y not being available across cells when each cell was run independently — all of which I fixed by making each cell self-contained with its own imports and data loading.
