In this lab, I learned how to systematically improve machine learning models by applying cross-validation, hyperparameter tuning, and structured model comparison using the Wine dataset. I converted raw data into a proper DataFrame, split it for training and testing, and trained a Logistic Regression baseline before exploring more robust evaluation through 5-fold cross-validation. I also tuned a KNN classifier manually and through GridSearchCV, then compared it against Logistic Regression and Decision Tree using CV scores to select the best final model. The main difficulties I faced were understanding why cross-validation gives more reliable results than a single train-test split, figuring out how GridSearchCV works internally and how to interpret its output, and deciding which model to select when scores are close — since a small difference in CV mean doesn't always clearly point to one winner.
