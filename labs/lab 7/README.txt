In this lab, I learned how to preprocess real-world datasets for artificial intelligence and machine learning by loading data from CSV and JSON files, inspecting datasets, handling missing values, merging multiple datasets, cleaning inconsistent categorical data, creating new features, and applying Min-Max normalization to numeric columns. I also learned how to build a reusable preprocessing function so the same cleaning steps can be applied to future datasets automatically. While working on the lab, I faced difficulties in identifying non-standard missing values like "?", deciding the best strategy for filling missing data, understanding different merge types, cleaning inconsistent city names, and normalizing only numeric columns without affecting categorical data. Overall, this lab helped me understand the importance of data preprocessing and how messy real-world data must be cleaned before it can be used for machine learning models.
